Git é um sistema de controle de versão que permite acompanhar e organizar as alterações feitas em um projeto. Já o GitHub é uma plataforma online usada para armazenar, compartilhar e colaborar em projetos de programação. Um commit é um registro das alterações realizadas no código, acompanhado de uma mensagem que explica o que foi modificado. Um repositório é o local onde ficam os arquivos e o histórico do projeto. Uma branch é uma ramificação que permite desenvolver novas funcionalidades separadamente, enquanto o merge une as alterações de diferentes branches. O push envia as alterações locais para o GitHub, o pull recebe as atualizações do repositório remoto e o clone cria uma cópia local de um projeto existente. Essas ferramentas facilitam a organização, a segurança e o trabalho em equipe no desenvolvimento de software.
